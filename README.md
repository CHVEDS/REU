# Цифровая инфраструктура клуба биохакинга и здоровья

MVP из трёх связанных модулей (см. ROAD_MAP): Telegram-бот, бот MAX и веб
личный кабинет — все три работают с одной локальной SQLite базой
`club.sqlite3` и запускаются на машине разработчика без внешних серверов.

## Что делает система

- Регистрация участника (имя, факультет, направление в клубе) — в Telegram
  или в MAX, профиль общий для всей системы.
- Ежедневный трекинг простых привычек (сон, вода, активность, цифровая
  гигиена) инлайн-кнопками, с начислением баллов за каждую отметку.
- Челлендж «7 дней ресурса первокурсника» (можно добавить свои в БД).
- Веб-личный кабинет — «цифровой паспорт участника»: баллы, история
  привычек, статус челленджа. У каждого участника своя ссылка
  `/profile/<token>`, которую бот присылает по команде `/profile`.
- Служебная страница `/` со списком всех участников и формой ручного
  начисления баллов (например, за офлайн-мероприятие).

## Структура проекта

```
biohacking_club/
├── config.py              # настройки из .env
├── database/
│   └── db.py              # схема SQLite + вся работа с БД
├── bot/
│   ├── common.py           # общая логика для обоих ботов
│   ├── registration.py     # пошаговая регистрация (в памяти)
│   ├── telegram_bot.py     # бот на aiogram
│   └── max_bot.py          # бот на REST API MAX (aiohttp)
├── web/
│   ├── app.py               # Flask-приложение
│   └── templates/           # HTML-шаблоны
├── run_all.py              # запускает веб + оба бота одним процессом
├── run_telegram_bot.py     # запуск только Telegram-бота (по отдельности)
├── run_max_bot.py          # запуск только бота MAX (по отдельности)
├── run_web.py               # запуск только веб-кабинета (по отдельности)
├── setup.bat / setup.sh     # установка зависимостей (venv + pip)
├── start.bat / start.sh     # установка + запуск одной командой
├── requirements.txt
└── .env.example
```

## Быстрый старт — одна команда

Ничего вручную ставить не нужно. Python 3.10+ должен быть уже установлен
(https://www.python.org/downloads/, при установке на Windows отметить
галочку «Add python.exe to PATH»). Дальше:

**Windows** — дважды кликнуть `start.bat` (или в консоли: `start.bat`).

**Linux / macOS** — в терминале:
```bash
./start.sh
```

Эта команда сама:
1. создаст виртуальное окружение `venv`, если его ещё нет;
2. поставит все зависимости из `requirements.txt`;
3. создаст `.env` из `.env.example`, если `.env` ещё нет;
4. инициализирует базу `club.sqlite3` (таблицы создаются автоматически);
5. запустит веб-кабинет на http://127.0.0.1:5000 и обоих ботов — всё в
   одном процессе (`run_all.py`).

При самом первом запуске токены ботов ещё не заполнены — в консоли будет
предупреждение, что Telegram-бот и/или бот MAX пропущены, но веб-кабинет
при этом всё равно поднимется. Впишите токены в появившийся файл `.env`
(см. раздел ниже, где их взять) и запустите `start.bat` / `./start.sh`
ещё раз — теперь стартуют уже все три модуля.

### Частая проблема на Windows: "не удаётся найти указанный файл"

Если `start.bat` падает на шаге создания venv с ошибкой вида
`Не удаётся найти указанный файл`, почти наверняка `python` в PATH — это
заглушка Microsoft Store, а не настоящий Python (реального интерпретатора
за ней нет). Проверить просто: в командной строке ввести `python` без
аргументов — если открывается Microsoft Store, это оно.

Как исправить:
1. Установить настоящий Python 3.10+ с https://www.python.org/downloads/windows/
   — на шаге установки обязательно отметить галочку **«Add python.exe to PATH»**.
2. Отключить сам alias-заглушку: **Параметры → Приложения → Дополнительные
   параметры приложений → Псевдонимы выполнения приложений** — выключить
   переключатели напротив `python.exe` и `python3.exe`.
3. Закрыть и заново открыть терминал (чтобы PATH перечитался) и снова
   запустить `start.bat`.

`setup.bat` сам старается в первую очередь использовать команду `py -3`
(её ставит официальный установщик python.org и она этой проблеме не
подвержена) — если `py` доступна в системе, шаг 2 можно пропустить.

### Ошибка сборки: "Microsoft Visual C++ 14.0 or greater is required" / "linker link.exe not found"

Значит у вас очень свежая версия Python (например, только что вышедшая), и
для неё ещё не готовы бинарные сборки (wheel) у одного из пакетов — pip
пытается собрать его из исходников, а для этого на Windows нужны компилятор
C++ и Rust, которых обычно нет. В `requirements.txt` версии уже заданы
диапазоном, а не жёстко, поэтому pip сам подбирает свежую сборку с готовым
wheel — но если конкретно для вашей версии Python её пока ни у кого нет,
проще всего использовать чуть менее свежий, но широко поддерживаемый Python:

1. Поставить Python 3.11–3.13 с https://www.python.org/downloads/windows/
   (галочка «Add python.exe to PATH»).
2. Удалить папку `venv` в проекте.
3. В консоли из папки проекта: `py -3.12 -m venv venv` (либо `py -3.11` /
   `py -3.13` — какая версия установлена).
4. Снова запустить `start.bat`.

Остановить всё — закрыть окно консоли или нажать `Ctrl+C`.

## Получение токенов

**Telegram**: напишите [@BotFather](https://t.me/BotFather) в Telegram,
команда `/newbot`, следуйте инструкциям, вставьте выданный токен в
`.env` → `TELEGRAM_BOT_TOKEN`.

**MAX**: внутри мессенджера MAX найдите `@MasterBot`, создайте бота через
него — он выдаст токен. Подробности и актуальный процесс:
https://dev.max.ru/docs-api. Вставьте токен в `.env` → `MAX_BOT_TOKEN`.

Оба бота работают независимо — можно запускать только один, если второй
пока не нужен (второй будет просто пропущен с предупреждением в логе).

## Запуск по отдельности (для отладки)

Если нужно смотреть логи каждого модуля отдельно, можно не использовать
`run_all.py`, а поднять всё по отдельности в трёх терминалах (после
`setup.bat` / `./setup.sh`, все три читают/пишут в один и тот же
`club.sqlite3`):

```bash
python run_telegram_bot.py   # Telegram-бот
python run_max_bot.py        # бот MAX
python run_web.py            # веб личный кабинет, http://127.0.0.1:5000
```

## Как это соотносится с системой баллов клуба

В коде — упрощённая версия: автоматические баллы начисляются за ежедневные
отметки привычек. Баллы за более крупный вклад (съёмка ролика, грантовая
заявка, проведение мероприятия и т.д. — см. раздел «Система баллов» в
описании клуба) начисляются вручную через служебную страницу `/` веб-
кабинета (`db.add_points(...)` можно вызвать и напрямую из Python/консоли
администратора).

## Что можно добавить дальше

- Полноценная админ-панель с авторизацией (сейчас страница `/` открыта без
  пароля — подходит только для локального запуска, не для интернета).
- Больше привычек и своих челленджей — их не нужно кодить, достаточно
  добавить строки в таблицы `habits` / `challenges` в БД.
- Уведомления/напоминания от бота по расписанию (утренний чек-ин и т.п.).
- Экспорт рейтинга участников по баллам (сейчас есть только список,
  сортировка/топ можно добавить SQL-запросом в `database/db.py`).

## Важное замечание про MAX Bot API

API мессенджера MAX моложе и активнее меняется, чем Telegram Bot API.
Реализация в `bot/max_bot.py` написана по официальной документации
(`dev.max.ru/docs-api`) на сентябрь 2026 года: long polling через
`GET /updates`, отправка через `POST /messages`, ответ на кнопки через
`POST /answers`. Если формат событий изменится, включите подробные логи
(`logging.DEBUG`) и посмотрите реальный JSON в `update["message"]` /
`update["callback"]`, чтобы поправить функции `_extract_*` в этом файле.
